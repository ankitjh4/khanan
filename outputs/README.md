# KHANAN outputs

This directory contains the current derived release artifacts. It is organized as follows:

- The root contains the v0.12 geospatial feature baseline and unchanged v0.6 prospectivity model in the completed v1.0-alpha.30 / Alpha 3.0 release: the 254-entity v1 ontology, IBM abandoned-mine, concession and State Review occurrence context, reviewed State MBS geometries and Andhra status evidence, metadata-only NGDR/GSI service audit, EMAG2v3 and SoilGrids context, EarthChem analytical geochemistry, nationwide Sentinel-2 surface context, three paired feature-ablation experiments, an independent official-block transfer diagnostic, a partial GSI/OGD mineral-deposit catalogue preview, candidate CSV/GeoJSON, crosswalks, release governance, completion and independent audits, checksums and deterministic bundle.
- `archive/releases/` contains superseded local release bundles and is not committed to Git.
- `diagnostics/workbook/` contains local workbook renders, inspections and formula-error scans and is not committed to Git.

The full `india_mining_prospectivity_grid_h3_r6.csv` is intentionally excluded from the Git checkout because it exceeds GitHub's normal single-file limit. It remains available locally and inside `india_mining_dataset_csv_bundle_v1.0-alpha.30.zip`.

The v1 material layer comprises `india_material_ontology_v1.csv` (254 typed entities), `material_source_term_crosswalk_v1.csv` (611 audited terms), and `material_ontology_validation_v1.json`. The crosswalk maps 602 terms and preserves nine nonspecific unresolved terms. Alpha.23 maps all 101 IBM State Review material terms, adds 21 source-observed entities and verifies that model-grid and candidate hashes remain unchanged. The IBM context layer comprises 82 abandoned-mine records, 123 official lease-distribution rows and 97 auction-granted concession rows. The alpha.16 State MBS audit reviews all 97 rows: 92 exact historical document selections, five Andhra rows with no exact match in the current public State index, 67 admitted source footprints and 25 selected-MBS records withheld. The separate five-row Andhra status layer retains dated official-secondary evidence and one Mincheri auction-date conflict without claiming current operation or creating geometry. The State Review layer has 586 occurrence-geography rows, 1,742 explicit district-crosswalk rows and a sparse 59,872-cell H3 context table. The EMAG2 layer comprises `india_emag2v3_magnetic_features_h3_r6.csv` (88,857 H3 cells), feature validation, and 50 material-level plus 70 fold-level ablation records. The SoilGrids layer comprises `india_soilgrids_v2_soil_features_h3_r6.csv` (88,857 cells), feature validation covering 54 WCS rasters, and another 50 material-level plus 70 fold-level ablation records. The alpha.17 EarthChem layer comprises 13 sample rows and 1,323 long-form observations at two published coordinate sites, with CC-BY-4.0 attribution, analytical methods, qualifiers, source-cell lineage and explicit model exclusion. Alpha.18 adds `india_sentinel2_surface_context_h3_r6.csv` (88,857 cells), a 950-scene manifest, separate validation and a coverage/surface-context map. Alpha.19 adds 50 material-level and 70 fold-level Sentinel-2 ablation records; no material passes all production-admission gates. Alpha.20 adds 50 material-summary rows and 221 observations from 151 target-mapped official block footprints within a screened pool of 166; no material passes all statistical gates, source-label independence remains unresolved and no ranking changes. Alpha.21 adds all 78 records exposed by the public previews of eight GSI/OGD deposit catalogues that report 381 records in total. Its incomplete, non-random preview rows and coordinate assumptions are explicit. Ontology or feature inclusion is not model eligibility: current prediction columns still use the 50 retained v0.6 targets, and every newer context layer remains excluded from scoring.

Alpha.24 adds `release_artifact_manifest.csv`, which freezes 44 CSV/GeoJSON artifacts by schema, key, evidence role, model-use restriction, hash and scope; `coverage_gap_register.csv`, which consolidates 38 source-specific and 20 project-wide limitations; and a complete 1,928-row `data_dictionary.csv` with one definition for every published CSV column. See the repository root `README.md`, `source_registry.csv`, these governance tables, and `validation_report.json` before using the data.

Alpha.25 adds `independent_release_verification.json` and a standard-library verifier that treats the finished ZIP as an evaluator input. The archive now includes every manifest-referenced builder and all declared reproduction entry points. The report verifies bundle integrity, schema/key/hash contracts, dictionary and gap coverage, validation gates, unchanged model hashes, candidate/grid parity and interpretation guardrails.

Alpha 3.0 adds `india_mining_candidate_areas_validation_gated.geojson`, an exact typed Polygon view of all 2,784 candidate CSV rows, and `alpha3_completion_audit.json`, which passes all 12 consolidated completion requirements. The final independent verifier also checks feature IDs, geometry, typed arrays, numeric fields and per-row hashes. The milestone closes the declared project scope without claiming discoveries, reserves, grades, legal rights or field validation.
