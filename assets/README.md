# KHANAN assets

Repository-facing maps and figures live here. Each data visualization must be reproducible from a script under `scripts/` and must state its release version and interpretation limits.

- `maps/khanan-india-prospectivity-overview-v0.6.png` is generated by `scripts/plot_khanan_overview.py`.
- `maps/khanan-emag2-magnetic-context-v0.7.png` is generated by `scripts/plot_emag2_context.py`; it separates the EMAG2v3 magnetic anomaly from its error/source-quality context and states that the layer does not yet affect candidate rankings.
- `maps/khanan-soilgrids-context-v0.8.png` is generated by `scripts/plot_soilgrids_context.py`; it maps surface pH, clay and soil-organic-carbon predictions and states that the complete soil layer remains context only.
- `maps/khanan-ibm-auction-mbs-geometries-alpha9.png` is the historical alpha.9 view with eight admitted State MBS source footprints.
- `maps/khanan-ibm-auction-mbs-geometries-alpha10.png` is the historical alpha.10 view with ten admitted State MBS source footprints.
- `maps/khanan-ibm-auction-mbs-geometries-alpha11.png` is generated by `scripts/plot_ibm_auction_mbs_geometries.py`; it locates fourteen admitted State MBS source footprints across Chhattisgarh, Goa, Uttar Pradesh and Karnataka and states the reviewed-withheld and incomplete national review scope.
- `figures/khanan-emag2-spatial-ablation-v0.1.png` is generated by `scripts/plot_emag2_ablation.py`; it shows paired material AUC changes, spatial-group bootstrap intervals and high-score recall changes.
- `figures/khanan-soilgrids-spatial-ablation-v0.1.png` is generated by `scripts/plot_soilgrids_ablation.py`; it shows paired material AUC changes, spatial-group bootstrap intervals and high-score recall changes after adding the soil feature family.
