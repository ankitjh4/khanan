# KHANAN assets

Repository-facing maps and figures live here. Each data visualization must be reproducible from a script under `scripts/` and must state its release version and interpretation limits.

- `maps/khanan-india-prospectivity-overview-v0.6.png` is generated by `scripts/plot_khanan_overview.py`.
- `maps/khanan-emag2-magnetic-context-v0.7.png` is generated by `scripts/plot_emag2_context.py`; it separates the EMAG2v3 magnetic anomaly from its error/source-quality context and states that the layer does not yet affect candidate rankings.
- `maps/khanan-soilgrids-context-v0.8.png` is generated by `scripts/plot_soilgrids_context.py`; it maps surface pH, clay and soil-organic-carbon predictions and states that the complete soil layer remains context only.
- `maps/khanan-ibm-auction-mbs-geometries-alpha9.png` is the historical alpha.9 view with eight admitted State MBS source footprints.
- `maps/khanan-ibm-auction-mbs-geometries-alpha10.png` is the historical alpha.10 view with ten admitted State MBS source footprints.
- `maps/khanan-ibm-auction-mbs-geometries-alpha11.png` is the historical alpha.11 view with fourteen admitted State MBS source footprints across Chhattisgarh, Goa, Uttar Pradesh and Karnataka.
- `maps/khanan-ibm-auction-mbs-geometries-alpha12.png` is the historical alpha.12 view with seventeen admitted State MBS source footprints.
- `maps/khanan-ibm-auction-mbs-geometries-alpha13.png` is the historical alpha.13 view; it keeps the seventeen admitted footprints, adds an explicit Andhra Pradesh status-evidence-only panel, and states the reviewed, withheld and incomplete national scope.
- `maps/khanan-ibm-auction-mbs-geometries-alpha14.png` is the historical alpha.14 view; it adds a Maharashtra panel and seven admitted State MBS source footprints while preserving explicit withheld and incomplete-scope counts.
- `maps/khanan-ibm-auction-mbs-geometries-alpha15.png` is the historical alpha.15 view; it adds a Madhya Pradesh panel and fifteen admitted Phase-XI State MBS source footprints while preserving explicit withheld and incomplete-scope counts.
- `maps/khanan-ibm-auction-mbs-geometries-alpha16.png` is generated by `scripts/plot_ibm_auction_mbs_geometries.py`; it completes the 97-row IBM review and adds a Rajasthan panel with 28 admitted historical State MBS source footprints while preserving all source conflicts and withholding decisions.
- `maps/khanan-earthchem-lithium-geochemistry-alpha17.png` is generated by `scripts/plot_earthchem_geochemistry.py`; it locates the two published EarthChem coordinate sites, summarizes 13 bulk-rock lithium measurements and the 1,323-row analytical scope, and states that targeted petrological samples are context rather than discovery evidence.
- `maps/khanan-sentinel2-surface-context-alpha18.png` is generated by `scripts/plot_sentinel2_surface_context.py`; it maps two-season clear-land coverage, not-vegetated support and a broad bare-surface SWIR ratio while explicitly excluding the layer from mineral-identification and discovery claims.
- `maps/khanan-gsi-ogd-deposit-preview-alpha21.png` is generated by `scripts/plot_gsi_ogd_deposit_preview.py`; it maps the 78 rows exposed by eight historical GSI/OGD catalogue preview endpoints, contrasts those rows with 381 reported catalogue records, and labels the non-random, incomplete scope and model exclusion.
- `maps/khanan-ibm-state-review-occurrence-context-alpha23.png` is generated by `scripts/plot_ibm_imyb_state_review_occurrences.py`; it maps the count of IBM 2024 State Review material terms inherited by unambiguous 2011 districts after complete ontology reconciliation and labels the district-wide, non-predictive interpretation boundary.
- `figures/khanan-emag2-spatial-ablation-v0.1.png` is generated by `scripts/plot_emag2_ablation.py`; it shows paired material AUC changes, spatial-group bootstrap intervals and high-score recall changes.
- `figures/khanan-soilgrids-spatial-ablation-v0.1.png` is generated by `scripts/plot_soilgrids_ablation.py`; it shows paired material AUC changes, spatial-group bootstrap intervals and high-score recall changes after adding the soil feature family.
- `figures/khanan-sentinel2-spatial-ablation-v0.1.png` is generated by `scripts/plot_sentinel2_ablation.py`; it shows paired material AUC changes, spatial-group bootstrap intervals and high-score recall changes after adding the compact Sentinel-2 surface feature family.
- `figures/khanan-official-block-transfer-v0.1.png` is generated by `scripts/plot_official_block_transfer.py`; it compares unchanged v0.6 scores with source-held-out official auction/exploration-block centroids and states the small-support, confidence-interval and knowledge-independence limits that prevent discovery or production claims.
